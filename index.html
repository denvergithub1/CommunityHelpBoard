Connect Google Sheets

Posts are saved locally in your browser. To sync across devices, connect a Google Sheet. You'll need to create an Apps Script web app that acts as the write endpoint.

Create a Google Sheet with columns: Title Category Description ImageURL AudioURL Rating Timestamp
Open Extensions → Apps Script. Paste the provided doGet/doPost script (see README). Deploy as Web App — "Anyone" can access.
Copy your Sheet ID from the URL and your Apps Script Web App URL, and paste both below.

Found in the sheet URL: …/spreadsheets/d/[THIS PART]/edit

Leave blank to use read-only mode (loads posts, can't submit).

Create a key at console.cloud.google.com → Credentials. Enable Sheets API. Restrict to your domain.
